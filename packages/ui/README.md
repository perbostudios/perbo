# `@perbo/ui`

Shared React primitives and design tokens for Perbo: buttons, badges, panels, fields, notices, empty states and focus-contained native dialogs. The desktop owns its original artwork registry and feature views. This package has no filesystem, IPC, provider, database or application-state dependency.

Import components from `@perbo/ui` and the tokens from `@perbo/ui/tokens.css`. Prefer a shared variant/token over a screen-specific copy. Keep control labels accessible when artwork is decorative; preserve visible keyboard focus and reduced-motion behavior.
